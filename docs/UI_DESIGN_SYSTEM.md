# 默迹 UI 设计系统 v1.1

## 产品与用户

默迹是 Android 本地优先的个人自动记账工具。核心用户依赖微信或支付宝消费，希望持续看清钱的去向，但不愿为每笔交易重复录入；他们同时重视隐私、数据可迁移和自动识别的可纠正性。

界面的首要任务不是展示更多指标，而是让用户快速确认三件事：本月花了多少、今天发生了什么、自动记账是否正常。视觉气质采用“安静账簿”：克制、可信、可长期阅读，避免金融交易终端、通用 AI 仪表盘和过度拟物。

## 视觉原则

1. 内容先于容器：通过排版、留白和细分隔线建立层级，常规内容不套卡片。
2. 金额先于装饰：首页与统计页各只有一个主金额，其余数据退为次级角色。
3. 单一强调色：玉绿色只表达选中、收入、正向状态和主操作。
4. 真实原生：保留 Material 3 的语义、触控、系统栏、底部导航、Sheet、Dialog 和输入行为。
5. 双主题同构：深色主题改变明度关系，不改变信息结构和语义色角色。

## 颜色角色

| 角色 | 浅色 | 用途 |
| --- | --- | --- |
| Background | `#F8F7F3` | 暖纸色页面底色 |
| Surface | `#FFFEFA` | 底部导航、弹层与需要区分的交互表面 |
| Ink | `#1C211E` | 主文字、支出金额 |
| Muted | `#6D746F` | 标签、说明、非活跃状态 |
| Primary | `#1F6B4F` | 选中态、收入、主操作 |
| Primary Container | `#DCEDE5` | 选中指示与弱强调背景 |
| Surface Variant | `#EDEEE9` | 图标底、进度轨道 |
| Outline Variant | `#DFE2DD` | 细分隔线 |
| Error | `#B33A32` | 校验错误、破坏性状态 |

## 排版

- 字体：Android 系统无衬线字体；金额使用系统等宽字体，保证数字列稳定。
- Display 40/48sp：页面唯一主金额。
- Headline 30/38sp、25/32sp、21/28sp：页面标题、模块标题、Sheet 标题。
- Title 19/26sp、16/23sp、14/20sp：模块、账单商户、日期分组。
- Body 16/24sp、14/21sp、12/18sp：正文、说明、次级标签。
- Label 14/20sp、12/16sp、11/16sp：导航、状态与节标题。
- 中文标题使用 SemiBold，正文不使用大面积粗体；金额不通过绿色来表达“重要”。

## 间距与尺寸

- 基础网格：4dp；主要节奏：8、12、16、20、24、32、48dp。
- 页面水平边距：24dp；工具栏紧凑边距：12dp。
- 列表行垂直内边距：12–14dp；触控区域不小于 48dp。
- 图标容器：40–42dp，图标 20–21dp。
- 底部导航遵循 Material 3 高度与系统导航栏 Insets。

## 圆角、层级与海拔

- 小组件 6dp；图标底与输入 10–14dp；Sheet 24–30dp。
- 常规账单、设置行和统计模块不使用卡片。
- 页面层级：Background → Surface（导航/弹层）→ Surface Variant（局部状态）。
- 默认不使用阴影；只有 Modal Bottom Sheet、Dialog 等真实浮层使用系统海拔。
- 禁止玻璃拟态、装饰渐变、发光、嵌套卡片和无语义胶囊。

## 图标

- 使用 Material Symbols Outlined，保持 2dp 左右视觉笔画。
- 图标只承担操作或分类识别，不用于纯装饰。
- 交互图标必须有中文 `contentDescription`；装饰或已有文本标签的图标设为 `null`。
- 分类 emoji 保留为用户数据，置于弱表面方形容器中，不与系统操作图标混用。

## 交互状态

- 默认：Ink / Muted 建立层级。
- 按压：使用 Material ripple，保留至少 48dp 命中区。
- 选中：Primary 图标与文字 + Primary Container 指示器；不只依赖颜色，文字与形状同步变化。
- 禁用：使用 Material 默认禁用透明度，并保留可理解标签。
- 错误：Error 文本靠近输入，不用全屏红色或抖动。
- 空态：说明原因和唯一下一步，不使用装饰插画填充空间。
- 加载：数据读取超过可感知阈值时使用局部进度，不阻塞底部导航。

## 页面层级

- 账本：首页工具栏 → 主金额 → 今日/预算摘要 → 日期分组 → 交易行。
- 统计：页面标题与期间切换 → 主金额 → 收入/结余 → 趋势 → 分类排行。
- 我的：页面标题与隐私定位 → 自动记账 → 账本 → 数据 → 外观；通过节标题和分隔线分组。
- 编辑：Modal Bottom Sheet 承载高频录入；金额与方向优先，高级字段后置。

## 适配与可访问性

- 所有页面使用系统 Insets，支持边到边绘制。
- LazyColumn 支持长列表；文本允许换行，避免固定文本高度。
- 关键正文对比度目标至少 4.5:1，控件边界和图标至少 3:1。
- 不从静态截图判断 TalkBack 顺序、动态字体、键盘避让和横屏表现；这些必须在运行态单独验证。
